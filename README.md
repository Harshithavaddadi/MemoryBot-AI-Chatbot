🤖 MemoryBot AI Chatbot

An AI-powered chatbot built using Python, Streamlit, and Google's Gemini API. MemoryBot provides a simple, interactive interface for chatting with an AI assistant and maintaining conversation context during a session.

✨ Features

- 💬 Interactive AI chat interface
- 🧠 Conversation context during the current chat session
- 📜 Sidebar chat history
- 🗑️ Clear Chat functionality
- ⚡ Powered by Google Gemini
- 🌐 Web-based interface built with Streamlit

🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google Gen AI Python SDK

📁 Project Structure

```text
MemoryBot-AI-Chatbot/
├── app.py

└── README.md
```

⚙️ Installation and Setup

1. Clone the repository

```bash
git clone https://github.com/Harshithavaddadi/MemoryBot-AI-Chatbot.git
cd MemoryBot-AI-Chatbot
```

2. Install dependencies

```bash
pip install -r requirements.txt
```
3. Configure the Gemini API key

Set your Gemini API key as an environment variable named `GEMINI_API_KEY`.

Never commit your API key to GitHub.

4. Run the application

```bash
streamlit run app.py
```

🔐 Security

Keep your Gemini API key private. For deployment, configure it using the hosting platform's secrets settings.

🚀 Deployment

This project can be deployed using Streamlit Community Cloud by connecting the GitHub repository and configuring the required secrets.
